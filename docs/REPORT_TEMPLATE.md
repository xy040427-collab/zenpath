# 择境 ZENPATH — Agent 执行报告模板

> 每次 Agent 完成任务后，必须按此模板输出报告。
> 不允许跳过报告，不允许省略任何必填项。

---

---

## 使用说明

1. Agent 完成任务后，**必须**按此模板输出完整报告
2. 不允许省略"运行命令"和"命令结果"
3. 不允许省略"安全检查"
4. 不允许省略"未完成项"
5. 如果某项不适用，写"N/A"并说明原因
6. 报告应保存到 `reports/agent-runs/` 目录（后续阶段实现）
