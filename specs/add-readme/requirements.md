# Spec: 新增项目 README.md

> 状态：Approved
> 创建日期：2026-06-29

---

## 1. 背景

项目目前没有 README.md，新开发者或 AI Agent 无法快速了解项目概况、技术栈、启动方式和规则文档位置。

## 2. 用户故事

作为项目协作者，我希望打开仓库就能看到 README.md，以便快速了解项目是什么、怎么跑、规则在哪。

## 3. 必须实现

- [ ] 新增根目录 `README.md`
- [ ] 包含项目名称和简介
- [ ] 包含技术栈
- [ ] 包含启动命令
- [ ] 包含构建命令
- [ ] 包含规则文档入口

## 4. 不做什么

- 不修改任何业务代码
- 不修改 frontend/ 或 backend/
- 不新增依赖

## 5. 允许修改范围

| 文件 | 类型 |
|------|------|
| `README.md` | 新增 |

## 6. 禁止修改范围

所有业务代码、配置文件、数据库。

## 7. 验收标准

- [ ] README.md 存在
- [ ] 内容包含项目名、技术栈、启动命令
- [ ] 不影响任何业务功能
- [ ] `npm run build` 通过
- [ ] Python compileall 通过
